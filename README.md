# QADAMIX — MVP платформы грузоперевозок

Три части на одном API:

| Часть | Папка | Для кого | Технологии |
|---|---|---|---|
| API и база | `server/` | — | Node.js 22+, Express 5, PostgreSQL 18, Zod |
| Кабинет логиста | `web/` | логисты, админ | React 19, Vite, React Router, Recharts |
| Приложение водителя | `mobile/` | водители | Expo SDK 57 (React Native), Expo Router |
| AI-диспетчер | `server/src/assistant/` | логисты и водители | Claude API (tool use) или режим правил |

`prototype/` — первая статичная копия сайта, `ANALYSIS.md` — разбор исходного макета.

## Что умеет

**Логист (сайт):** создаёт груз (или вставляет текст из WhatsApp — поля заполнятся сами), видит рыночную ставку по истории рейсов, получает подбор машин с оценкой и причинами, приглашает водителей, выбирает из откликов, следит за рейсом по статусам, печатает договор-заявку, ставит оценку водителю, смотрит аналитику (рейсы, оборот, ₸/км, направления, кузова, время поиска машины).

**Водитель (приложение):** вход по номеру телефона, лента грузов, отсортированная по тому, насколько груз подходит его машине, отклик со своей ценой, приглашения от логистов, кнопки статуса рейса («на загрузке» → «выехал» → «доставлен») с городом и комментарием, профиль машины, статус «свободен/занят», уведомления.

**AI-диспетчер (в обоих):** ищет только по данным платформы через инструменты — грузы, свободные машины, подбор фуры под маршрут или груз, статус рейса, оценка ставки, обратная загрузка, статистика. Права ограничены ролью: водитель не видит чужие рейсы и телефоны логистов. Без ключа Claude работает в режиме правил и на непонятный вопрос честно отвечает, что понимает.

**Админ:** проверка документов водителей.

## Запуск в Docker (всё сразу)

```bash
docker compose up -d --build
```

| Что | Адрес |
|---|---|
| Кабинет логиста | http://localhost:8080 |
| Приложение водителя (веб-версия) | http://localhost:8081 |
| API | http://localhost:4000/api |

При первом запуске сервис `seed` создаёт схему и демо-данные; при следующих — пропускает, если в базе уже есть данные. Пересоздать демо-данные: `docker compose run --rm seed node src/seed.js --reset`. Ключ Claude передаётся из окружения: `ANTHROPIC_API_KEY=sk-ant-... docker compose up -d`.

## Запуск для разработки

Нужны Node.js 22.13+ и Docker Desktop (для базы).

```bash
docker compose up -d postgres
```

```bash
cd server
cp .env.example .env
npm install
npm run seed
npm run dev
```

API: http://localhost:4000/api. `npm run seed` создаёт демо-данные: 2 логиста, 12 водителей, ~150 рейсов за полгода.

```bash
cd web
npm install
npm run dev
```

Кабинет логиста: http://localhost:5173

```bash
cd mobile
npm install
npx expo start
```

Отсканируйте QR-код приложением **Expo Go** (Android / iOS). Телефон и компьютер должны быть в одной Wi-Fi сети — адрес API приложение определит само. Нажмите `w`, чтобы открыть приложение в браузере.

## AI-диспетчер на Claude

Добавьте в `server/.env` и перезапустите сервер:

```
ANTHROPIC_API_KEY=sk-ant-...
```

Используется `claude-opus-5-5` (можно сменить через `CLAUDE_MODEL`) с инструментами из `server/src/assistant/tools.js`. Включён серверный резерв (`fallbacks: "default"`): если модель откажет в ответе, запрос автоматически обработает резервная модель. История диалога хранится в `chat_sessions` целиком и только дописывается. Разбор текста заявки (`/api/cargos/parse`) тоже идёт через Claude, без ключа — по правилам.

## GPS

- **Приложение водителя** во вкладке «Рейс» → «Передавать GPS». Точка раз в 30 с или каждые 150 м. Без связи точки копятся в очереди на телефоне (до 5000) и уходят пачками, когда сеть появится. После «Груз доставлен» передача выключается сама.
- **Фоновая передача** (когда открыт навигатор или экран выключен) работает только в собственной сборке приложения: `npx eas-cli@latest build --profile development` или `npx expo run:android`. В Expo Go и в браузере GPS передаётся, пока приложение открыто: это ограничение Expo Go, а не приложения.
- **Сервер** (`server/src/routes/gps.js`) хранит трек в таблице `positions`, отбрасывает дубли и точки старше 7 дней или с точностью хуже 2 км, считает пройденное, остаток, прогресс, ETA (с учётом отдыха водителя) и ближайший город. Свежий GPS (до 6 ч) используется в подборе машин вместо города из профиля. Если водитель меняет статус без города, город подставляется по GPS.
- **Кабинет логиста**: карта рейса в карточке груза (план, фактический трек, машина, ETA) и карта парка в разделе «Водители» → «Карта».
- **Приватность**: точные координаты логист видит только у водителей на своих рейсах. Остальные машины показаны в их городе, примерно. Трек рейса доступен только заказчику, водителю и админу.

Имитация движения фуры для демо (без телефона):

```bash
cd server
node scripts/simulate-gps.mjs +77011000006 --interval=4 --step=4
```

Водитель Санжар Оспанов (рейс в пути Караганда → Шымкент) каждые 4 секунды сдвигается на 4 км к Шымкенту, на карте логиста машина едет в реальном времени.

## Проверка

```bash
cd server
node scripts/smoke.mjs
```

29 сквозных проверок API: вход, подбор, отклики, гонка двух принятий, переходы статусов, ставка, разбор текста, аналитика, валидация, права ролей, GPS (приём, дубли, трек, приватность, город по GPS), ассистент. Тест меняет данные — после него выполните `npm run seed`.

## Структура API

| Метод | Путь | Кто |
|---|---|---|
| POST | `/api/auth/request-code`, `/api/auth/verify` | все |
| GET | `/api/auth/me`, `/api/meta`, `/api/notifications` | все |
| GET/POST | `/api/cargos`, `/api/cargos/parse`, `/api/rate-estimate` | логист |
| GET/PATCH | `/api/cargos/:code` | логист; водитель — открытые и свои |
| GET | `/api/cargos/:code/matches`, `/api/cargos/:code/offers` | логист |
| POST | `/api/cargos/:code/invite`, `/api/offers/:id/accept`, `/api/offers/:id/reject`, `/api/cargos/:code/review` | логист |
| GET | `/api/drivers`, `/api/drivers/:id`, `/api/analytics` | логист |
| GET | `/api/market`, `/api/my/offers`, `/api/my/trips` | водитель |
| POST/DELETE | `/api/cargos/:code/offers`, `/api/offers/:id` | водитель |
| POST | `/api/cargos/:code/events` | назначенный водитель |
| PATCH | `/api/me/driver` | водитель |
| POST | `/api/assistant` | все |
| GET/POST | `/api/admin/drivers`, `/api/admin/drivers/:id/verify` | админ |

Схема базы — `server/migrations/001_init.sql`. Новые миграции кладите туда же с номером (`002_…sql`), они применяются при старте сервера.

## Что дальше

- **SMS:** подключить провайдера (Mobizon, SMSC.kz) в `server/src/routes/auth.js` и выключить `DEV_SHOW_OTP`.
- **Push-уведомления водителям:** `expo-notifications`. Сейчас приложение опрашивает сервер раз в 20–30 секунд.
- **Загрузка документов водителя:** фото прав и техпаспорта в объектное хранилище. Сейчас админ меняет статус проверки вручную.
- **ЭЦП (NCALayer) и ЭДО.** Сейчас договор-заявка печатается и сохраняется в PDF из браузера.
- **GPS из приложения:** `expo-location` вместо ручного выбора города.
- **Расстояния:** сейчас оцениваются по прямой ×1,25, точнее будет картографический сервис.
- **Сборка приложения в сторы:** `npx eas-cli@latest build`.
- **Деплой:** API и Postgres на VPS или в облаке, `web` — `npm run build` в любой статический хостинг с проксированием `/api`.
